# AI Workplace Hub

Build a modern, professional, responsive web app called AI Workplace Productivity Assistant (WorkAI).



Create ONE integrated SaaS dashboard with a sidebar and these 5 AI tools:



1. Smart Email Generator – Generate professional emails with Formal, Friendly, Professional, Persuasive and Apologetic tones. Allow users to edit, copy and regenerate emails.



2. Meeting Notes Summarizer – Summarize meeting notes and extract Key Points, Decisions, Action Items, Responsible Persons and Deadlines.



3. AI Task Planner – Users enter tasks with priority, deadline and duration. AI creates a realistic prioritized daily/weekly schedule.



4. AI Research Assistant – Users enter a topic and question. AI provides a clear summary, key findings, workplace applications and recommendations.



5. AI Workplace Chatbot – A conversational assistant that helps with emails, planning, summarizing, research and workplace productivity.



Dashboard



Include:



- Welcome message

- Quick-action cards for all 5 tools

- Statistics for Emails, Meetings, Tasks and Research

- Recent Activity



Design



Use a clean, modern SaaS design with:



- Left sidebar navigation

- Top header

- Professional typography

- Cards and icons

- Responsive desktop, tablet and mobile layouts

- Collapsible mobile sidebar

- Light/dark mode



AI Features



Use strong structured prompts with:



- Role

- Context

- User input

- Task

- Rules/constraints

- Required output format



AI outputs must be editable and have Copy, Edit, Regenerate and Clear buttons.



Include loading states, empty states and friendly error messages.



Responsible AI



Add a visible disclaimer:



“AI-generated content may contain errors. Users should review and verify AI responses before sending emails, making business decisions or relying on research. Do not enter confidential or sensitive information.”



Additional Pages



Create:

- Task Planner

- Research Assistant

- AI Chatbot

- Settings

- About

- Responsible AI



Branding:

WorkAI

“Work smarter. Communicate better. Get more done.”



Build the application as ONE connected professional platform, not separate websites. Make all navigation and interactions functional and presentation-ready for a CAPACITI AI Skill Accelerator Programme project.
